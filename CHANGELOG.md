# Changelog

## [Unreleased] - WezTerm Integration (2026-08-04)

### Added
- **WezTerm Theme Integration**: Added `wezterm.nix` module to automatically configure WezTerm to use the theme generated by DMS Matugen (`dank-theme.toml`).

### Changed
- **Home Manager Configuration**: Removed `wezterm` from the global package list in `home.nix` (nix-conf), as it is now managed declaratively by the `wezterm.nix` module in `shell-conf`.
